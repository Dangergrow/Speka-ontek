# ONTEK — Таблица заказов

![Version](https://img.shields.io/badge/version-4.5.0-blue)
![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-green)
![License](https://img.shields.io/badge/license-MIT-orange)

Профессиональное Windows-приложение для создания и редактирования таблиц заказов с экспортом в Excel.
---

## 🚀 Возможности

### 📊 Таблицы
- Создание таблиц с валютами RUB и USD (с НДС)
- Автоматический расчёт стоимости (Количество × Цена)
- Строка "Итого" с суммой всех позиций
- Нумерация строк
- 5 независимых рабочих окон с вкладками

### 💾 Excel
- Сохранение в `.xlsx` с формулами и форматированием
- Загрузка из `.xlsx` и `.xls`
- Обрезка чисел до 2 знаков после запятой
- Правильное отображение в Microsoft Excel

### 🎨 Интерфейс
- 4 цветовые темы (Синяя, Зелёная, Фиолетовая, Оранжевая)
- Тёмная и светлая тема
- Сайдбар с кнопками быстрого доступа
- Контекстное меню (правый клик)
- Анимации интерфейса

### ⌨ Горячие клавиши
- Все клавиши можно переназначить в настройках
- Поддержка русской раскладки

| Действие | По умолчанию |
|----------|--------------|
| Добавить строку | `Shift+A` |
| Удалить строку | `Shift+D` |
| Добавить колонку | `Shift+C` |
| Удалить колонку | `Shift+X` |
| Новая RUB | `Shift+1` |
| Новая USD | `Shift+2` |
| Отменить | `Shift+Z` / `Ctrl+Z` |
| Сохранить | `Shift+S` / `Ctrl+S` |
| Вставить | `Shift+V` / `Ctrl+V` |
| Поиск | `Ctrl+F` |
| Тема | `Ctrl+T` |
| Окна 1-5 | `Ctrl+1...5` |

### 💱 Курсы валют
- USD и EUR к рублю (ЦБ РФ)
- Обновление в реальном времени
- Стрелки роста/падения

### 🔍 Поиск
- `Ctrl+F` — поиск по таблице
- `F3` — следующее совпадение

### 💾 Сохранение настроек
- Тема, цвет, горячие клавиши сохраняются автоматически
- Восстановление при следующем запуске

### 🔄 Автообновление
- Проверка новых версий на GitHub
- Скачивание и установка обновлений

## 📥 Установка

### Способ 1: Установщик (рекомендуется)
1. Скачайте `ONTEK_Setup.exe` из [Releases](https://github.com/Dangergrow/Speka-ontek/releases/latest)
2. Запустите установщик
3. Выберите папку установки
4. Нажмите «Установить»
5. Ярлык появится на рабочем столе

### Способ 2: Портативная версия
1. Скачайте `ONTEK_Orders.exe` из [Releases](https://github.com/Dangergrow/Speka-ontek/releases/latest)
2. Запустите — программа готова к работе

### Системные требования
- Windows 10 или Windows 11 (64-bit)
- 50 МБ свободного места
- Не требует установки Python или браузера

## 🛠 Разработка

### Требования
- Python 3.11+
- Git

### Установка
```bash
git clone https://github.com/Dangergrow/Speka-ontek.git
cd Speka-ontek
pip install pywebview pyinstaller
Запуск без сборки
bash
python run.py
Сборка EXE
bash
pyinstaller --onefile --windowed --add-data "index.html;." --add-data "css;css" --add-data "js;js" --add-data "exceljs.min.js;." --add-data "xlsx.full.min.js;." --add-data "icon.ico;." --icon "icon.ico" --name "ONTEK_Orders" --hidden-import=webview --hidden-import=tkinter run.py

🔄 Автообновление
Программа проверяет version.json в репозитории. При выходе новой версии:

Показывает уведомление

Скачивает обновлённые файлы

Перезагружает интерфейс

Для выпуска обновления:

Увеличьте версию в version.json

Загрузите новые файлы на GitHub

Создайте Release с EXE
