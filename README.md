# ONTEK — Таблица заказов

Настольный редактор заказов и спецификаций. Python и pywebview запускают локальный интерфейс; ExcelJS сохраняет Excel, SheetJS читает таблицы. Это обновление оформления исходного проекта ветки 7.1: расчёты, структура данных и файловые операции сохранены.

## Новый интерфейс

Графитовая боковая панель, отдельные действия открытия и сохранения, пять рабочих вкладок, сгруппированная панель форматирования, новые карточки таблиц и диалоги. Шесть цветовых схем в светлом и тёмном режимах. Иконки нарисованы в SVG, без эмоджи. Новый `icon.ico` содержит девять размеров от 16 до 256 пикселей. Установщик оформлен в том же стиле.

Все ресурсы интерфейса локальные: для шрифтов, иконок и оформления интернет не нужен. Курсы загружаются существующим сетевым кодом; при недоступности источников программа сообщает об этом.

## Запуск и сборка Windows EXE

Распакуйте **весь** проект в папку. Используйте своё рабочее окружение Python, в котором собиралась предыдущая версия. Для нового окружения нужны Python с tkinter, pywebview и PyInstaller:

```bat
python -m pip install pywebview pyinstaller
python run.py
```

Для Windows-окна pywebview нужен установленный WebView2 Runtime. Сборку Windows EXE выполняйте на Windows.

**Запустите `build.bat`.** Результат: `dist\ONTEK_Orders.exe`. Скрипт использует прежний набор ресурсов и параметров сборки. Новая эмблема `css\brand.svg` автоматически попадает в EXE вместе с папкой `css`.

Прежняя ручная команда также подходит:

```bat
pyinstaller --onefile --windowed --add-data "index.html;." --add-data "css;css" --add-data "js;js" --add-data "exceljs.min.js;." --add-data "xlsx.full.min.js;." --add-data "icon.ico;." --icon "icon.ico" --name "ONTEK_Orders" --hidden-import=webview --hidden-import=tkinter run.py
```

Если нужен установщик, после сборки приложения запустите `build_setup.bat`. Получится `dist\ONTEK_Setup.exe` с приложением, интерфейсом и новой иконкой внутри. При необходимости собирайте в той же среде с `pywin32`, которую использовали раньше для создания ярлыков; имеющийся резервный способ через PowerShell сохранён.

### Как увидеть новый дизайн при обновлении

Существующий `run.py` извлекает интерфейс из EXE **только когда рядом с ним нет `index.html`**. Поэтому замена одного EXE в старой папке с оставшимся HTML не обновит оформление.

Для первого просмотра запустите новый EXE из отдельной пустой папки с правом записи. Для обновления установленной копии закройте приложение и используйте новый установщик либо замените вместе с EXE файлы `index.html`, `icon.ico`, `exceljs.min.js`, `xlsx.full.min.js` и папки `css`, `js` из этого архива. Сохраните свои файлы заказов и настройки. Не запускайте две копии одновременно: приложение использует прежний локальный порт 8765.

## Возможности редактора

- Пять рабочих окон; несколько таблиц RUB/USD в каждом, дублирование и удаление таблиц.
- Строки, столбцы, строки-заголовки и разделители между таблицами.
- Расчёт «Количество × Цена», итоги, валютные столбцы и конвертация по загруженному курсу.
- Формулы со ссылками на ячейки, SUM, AVG, MIN, MAX; наценка и скидка.
- Выделение, объединение ячеек, шрифты, выравнивание, цвет текста и заливки, заметки, копирование оформления.
- Поиск и замена, шаблоны структуры таблиц, контекстное меню, отмена поддерживаемых действий.
- Сохранение `.xlsx` с формулами и оформлением, загрузка Excel, CSV, печатное представление. Импорт остаётся прежним: он читает табличные данные, а не восстанавливает все элементы оформления экспортированного файла.
- Настройка высоты строк, отступов, шрифта, сетки, переноса текста и итоговой строки.
- Сохранение настроек и восстановление сессии. Настройки записываются в `settings.json` рядом с приложением и в локальное хранилище WebView; сессии и шаблоны — в локальное хранилище WebView. XLSX сохраняется отдельной командой.

## Основные клавиши

| Действие | Клавиши |
| --- | --- |
| Добавить / удалить строку | Shift+A / Shift+D |
| Добавить / удалить столбец | Shift+C / Shift+X |
| Новая таблица RUB / USD | Shift+1 / Shift+2 |
| Дублировать таблицу | Shift+U |
| Пересчитать | Shift+R |
| Конвертировать валюту | Shift+K |
| Открыть / сохранить | Shift+O / Shift+S |
| Отменить | Shift+Z или Ctrl+Z |
| Поиск / замена | Ctrl+F / Ctrl+H |
| Рабочие окна | Ctrl+1 … Ctrl+5 |
| Тёмная / светлая тема | Ctrl+T |

Переназначаемые сочетания доступны в настройках. Полный набор действий — в панели инструментов и контекстном меню.

## Структура

| Файл | Назначение |
| --- | --- |
| `run.py` | Локальный сервер, окно pywebview, файловые диалоги и мост Python |
| `installer.py` | Установка файлов, ярлык, запуск приложения |
| `index.html` | Разметка рабочего окна и диалогов |
| `css/style.css`, `css/themes.css` | Геометрия интерфейса и темы |
| `css/brand.svg`, `icon.ico` | Эмблема и иконка Windows |
| `js/core.js` | Состояние, утилиты, формулы, валюты, копирование |
| `js/table.js` | Таблицы, ячейки, выделение, редактирование |
| `js/ui.js` | Панели, меню, поиск, шаблоны, оформление |
| `js/system.js` | Сессии, настройки, импорт, экспорт, горячие клавиши |
| `js/init.js` | Инициализация и привязка команд |
| `exceljs.min.js`, `xlsx.full.min.js` | Исходные библиотеки Excel |
| `version.json` | Существующие метаданные версии |
| `build.bat`, `build_setup.bat` | Сборка приложения и установщика |

Сетевой механизм обновления в `run.py` оставлен как в исходнике. Он содержит обращения к старой структуре (`js/app.js`) и старой разметке, поэтому для установки этого редизайна используйте сборку/замену файлов выше. Автообновление не считается проверенным способом доставки этого изменения.

Проверки и границы проверки описаны в `DESIGN_NOTES.md`. Снимки интерфейса находятся в `preview`; товары на них — только данные для демонстрации, в начальной сессии приложения их нет.
